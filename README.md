# Droid Desserts 🍩🍦🍧

**Droid Desserts** adalah aplikasi seluler berbasis Android yang menampilkan daftar berbagai macam hidangan penutup (dessert) populer yang terinspirasi dari versi/nama rilis Android. Aplikasi ini menampilkan antarmuka yang bersih, modern, dan ramah pengguna untuk melihat deskripsi ringkas dari setiap makanan penutup.

## ✨ Fitur Utama

- **Daftar Dessert Interaktif**: Menampilkan daftar hidangan penutup lengkap dengan gambar lingkaran yang menarik.
- **Deskripsi Detail**: Penjelasan singkat mengenai karakteristik setiap makanan penutup:
    - **Donut**: *Glazed and sprinkled with candy.*
    - **Ice Cream Sandwich**: *Chocolate wafers with vanilla filling.*
    - **Froyo**: *Premium self-serve frozen yogurt.*
- **Desain Modern & Responsif**: Menggunakan elemen UI Android terkini dengan skema warna pastel yang nyaman di mata.

---

## 🛠️ Teknologi & Stack

- **Platform**: Android
- **Bahasa Pemrograman**: Kotlin / Java
- **UI Framework**: Jetpack Compose / XML Layouts
- **Arsitektur**: MVVM (Model-View-ViewModel)

## 🚀 Cara Menjalankan Proyek

1. **Clone repositori ini**:
   ```bash
   git clone https://github.com/username/droid-desserts.git
   ```

2. **Buka Proyek**:
    - Buka aplikasi **Android Studio**.
    - Pilih `Open an existing project` dan arahkan ke folder hasil clone.

3. **Build & Run**:
    - Tautkan perangkat Android fisik (aktifkan USB Debugging) atau jalankan Emulator.
    - Tekan tombol **Run** (`Shift + F10`) di Android Studio.
